Gherkin Glass is stable. Version 1.0.0 is on crates.io, installed with `cargo install gherkin-glass` or as a binary for five platforms, and it holds everything the two alphas brought, with pages that now fit a window 320 pixels wide. From this version on, page addresses, anchors, the command line and the configuration change in a breaking way only in a new major version. It is wired with [snapfit](https://marlon-sousa.com/snapfit-rs/).

[The release on GitHub](https://github.com/marlon-sousa/gherkin-glass/releases/tag/v1.0.0) has the full notes, and [the project's site](https://marlon-sousa.com/gherkin-glass/) shows what it makes of an example suite.
