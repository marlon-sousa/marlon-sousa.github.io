Itinera is out of beta. Specification 0.1.0 and its conformance cases are tagged and will not change, and Itinera 0.1.0 is released for Rust on crates.io, TypeScript on npm, and Kotlin and Java on Maven Central, each passing every case of tier 1. Each 0.1.0 holds the code of its 0.1.0-beta.7, so nothing written for the last beta breaks.

[The announcement on Itinera's site](https://itinera-dev.org/news/itinera-0.1.0/) links each release and its conformance report, and [Itinera's languages page](https://itinera-dev.org/languages/) has the line that adds it to a project.
