title: 'Itinera for Rust 0.1.0-beta.3 is released'
date: 2026-10-15
time: '17:16'
project: 'Itinera'
---

The third beta of Itinera for Rust is on crates.io, claiming tier 1 of specification 0.1.0. It makes the API friendlier without changing what a journey does: fewer marks on a step's parameters, step hooks that say what they decide, input adapters that say where a value comes from, and a shorter `Result`. It breaks code written for 0.1.0-beta.2.

[The announcement on Itinera's site](https://itinera-dev.org/news/rust-0.1.0-beta.3/) has the details, and `cargo add itinera@0.1.0-beta.3` adds it.
