O segundo alfa do Gherkin Glass, de novo só no GitHub, constrói um site só com os arquivos de funcionalidades que uma mudança toca, constrói prévias cujas páginas pedem aos buscadores que não as indexem, ganha uma página com todos os resultados de uma busca, reorganiza o layout de esquemas de cenário e de contextos, e encerra o `ghg serve` de forma ordenada.

[A versão no GitHub (em inglês)](https://github.com/marlon-sousa/gherkin-glass/releases/tag/v0.1.0-alpha.2) traz as notas.
