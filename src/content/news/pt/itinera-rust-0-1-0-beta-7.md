O sétimo beta para Rust não quebra nada escrito para o 0.1.0-beta.6. Um teste roteirizado só pede as tentativas que podem de fato acontecer, um input adapter assíncrono é recusado pelo compilador, e Rust agora passa pelos mesmos casos de conformidade que Kotlin e Java.

[O anúncio no site do Itinera (em inglês)](https://itinera-dev.org/news/rust-0.1.0-beta.7/) traz os detalhes.
