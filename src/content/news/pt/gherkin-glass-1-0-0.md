O Gherkin Glass está estável. A versão 1.0.0 está no crates.io, instalada com `cargo install gherkin-glass` ou como binário para cinco plataformas, e reúne tudo o que os dois alfas trouxeram, com páginas que agora cabem em uma janela de 320 pixels de largura. A partir desta versão, endereços de páginas, âncoras, a linha de comando e a configuração só mudam de forma incompatível em uma nova versão major. Ele é montado com o [snapfit (em inglês)](https://marlon-sousa.com/snapfit-rs/).

[A versão no GitHub (em inglês)](https://github.com/marlon-sousa/gherkin-glass/releases/tag/v1.0.0) traz as notas completas, e [o site do projeto (em inglês)](https://marlon-sousa.com/gherkin-glass/) mostra o que ele faz com uma suíte de exemplo.
