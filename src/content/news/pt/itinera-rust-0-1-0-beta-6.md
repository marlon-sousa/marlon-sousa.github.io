O sexto beta para Rust segue as mesmas duas propostas que o segundo beta para TypeScript. Um ID de jornada agora é uma string que não é vazia, criada com `JourneyId::try_from`, e código próprio que devolve o que a sua chamada não pode devolver continua simplesmente não compilando em Rust. Ele quebra código escrito para o 0.1.0-beta.5.

[O anúncio no site do Itinera (em inglês)](https://itinera-dev.org/news/rust-0.1.0-beta.6/) lista todas as mudanças.
