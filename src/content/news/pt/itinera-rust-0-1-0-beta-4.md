O quarto beta do Itinera para Rust segue os casos de conformidade mais novos. Dois input adapters com o mesmo nome agora são uma violação que o workflow reporta, e um abort diz qual input adapter falhou e para qual chave. Ele quebra código escrito para o 0.1.0-beta.3 nesses dois pontos.

[O anúncio no site do Itinera (em inglês)](https://itinera-dev.org/news/rust-0.1.0-beta.4/) lista todas as mudanças.
