O terceiro beta do Itinera para Rust está no crates.io, declarando o nível 1 da especificação 0.1.0. Ele torna a API mais amigável sem mudar o que uma jornada faz: menos marcações nos parâmetros de um passo, hooks de passo que dizem o que decidem, input adapters que dizem de onde vem um valor, e um `Result` mais curto. Ele quebra código escrito para o 0.1.0-beta.2.

[O anúncio no site do Itinera (em inglês)](https://itinera-dev.org/news/rust-0.1.0-beta.3/) traz os detalhes, e `cargo add itinera@0.1.0-beta.3` o adiciona.
