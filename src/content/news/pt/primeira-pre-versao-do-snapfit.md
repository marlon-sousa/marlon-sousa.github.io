O snapfit 0.1.0-alpha.1 saiu no GitHub: injeção de dependências para Rust verificada quando o programa compila. A ligação entre os componentes é declarada uma vez, em uma struct de contêiner, e os tipos do domínio continuam sendo Rust puro. Uma dependência faltando ou um ciclo é um erro de compilação, escrito como uma frase e apontando para o campo que o causa.

[A versão no GitHub (em inglês)](https://github.com/marlon-sousa/snapfit-rs/releases/tag/v0.1.0-alpha.1) traz as notas.
