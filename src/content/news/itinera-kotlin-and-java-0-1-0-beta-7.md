date: 2026-11-03

project: 'Itinera'
---

Itinera has two more languages. Its first release for the JVM, 0.1.0-beta.7, is on Maven Central under the group `org.itinera-dev`, for Kotlin and for Java at once, claiming tier 1 of specification 0.1.0. One core, written in Kotlin, serves both; annotations declare steps, policies and workflows, and a compiler plugin catches some mistakes before the program runs.

[The announcement on Itinera's site](https://itinera-dev.org/news/kotlin-and-java-0.1.0-beta.7/) shows what it brings.
