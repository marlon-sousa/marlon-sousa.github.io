date: 2026-10-27
time: '17:15'
project: 'Itinera'
---

The sixth Rust beta follows the same two proposals as TypeScript's second. A journey ID is now a string that is not empty, made with `JourneyId::try_from`, and custom code that returns what its call cannot return still simply does not compile in Rust. It breaks code written for 0.1.0-beta.5.

[The announcement on Itinera's site](https://itinera-dev.org/news/rust-0.1.0-beta.6/) lists every change.
