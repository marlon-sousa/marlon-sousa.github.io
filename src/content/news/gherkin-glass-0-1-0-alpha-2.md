The second alpha of Gherkin Glass, again on GitHub only, builds a site of only the feature files a change touches, builds previews whose pages ask search engines not to index them, gains a page listing every search result, lays out outlines and backgrounds anew, and stops `ghg serve` gracefully.

[The release on GitHub](https://github.com/marlon-sousa/gherkin-glass/releases/tag/v0.1.0-alpha.2) has the notes.
