Itinera has a second language. Its first TypeScript release, 0.1.0-beta.5, is on npm as the package `itinera`, under the tag `next`, claiming tier 1 of specification 0.1.0 and passing the same conformance cases as Rust. A workflow means in TypeScript exactly what it means in Rust; what changes is how it is written: decorators, type tokens built on Zod, and mistakes caught by the compiler rather than at run time.

[The announcement on Itinera's site](https://itinera-dev.org/news/typescript-0.1.0-beta.5/) shows what it brings.
