snapfit 0.1.0-alpha.1 is out on GitHub: dependency injection for Rust that is checked when the program compiles. The wiring is declared once, in a container struct, and the domain types stay plain Rust. A missing dependency or a cycle is a compile error, written as a sentence and pointing at the field that causes it.

[The release on GitHub](https://github.com/marlon-sousa/snapfit-rs/releases/tag/v0.1.0-alpha.1) has the notes.
