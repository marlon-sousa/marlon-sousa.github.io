date: 2026-11-04
time: '08:53'
project: 'Itinera'
---

The seventh Rust beta breaks nothing written for 0.1.0-beta.6. A scripted test asks only for attempts that can actually happen, an asynchronous input adapter is refused by the compiler, and Rust now passes the same conformance cases as Kotlin and Java.

[The announcement on Itinera's site](https://itinera-dev.org/news/rust-0.1.0-beta.7/) has the details.
