project: 'Itinera'

The fourth beta of Itinera for Rust follows the newest conformance cases. Two input adapters with one name are now a violation the workflow reports, and an abort says which input adapter failed and for which key. It breaks code written for 0.1.0-beta.3 in those two places.

[The announcement on Itinera's site](https://itinera-dev.org/news/rust-0.1.0-beta.4/) lists every change.
