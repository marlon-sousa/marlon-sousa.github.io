The second TypeScript beta follows two proposals the specification accepted after the first one. Custom code that returns what its call cannot return now aborts the journey, and a step hook returns `keepDefault()` or a lifecycle rather than nothing. It breaks code written for 0.1.0-beta.5.

[The announcement on Itinera's site](https://itinera-dev.org/news/typescript-0.1.0-beta.6/) lists every change.
