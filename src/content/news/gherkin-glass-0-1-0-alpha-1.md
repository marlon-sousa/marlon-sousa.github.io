Gherkin Glass 0.1.0-alpha.1 is out, three days after its first commit: a preview, released on GitHub only. It turns a folder of Gherkin feature files into a static website a product owner can navigate and read, with a page for every feature and folder, a link to every rule and scenario, search, and a folder tree, built for screen readers first.

[The release on GitHub](https://github.com/marlon-sousa/gherkin-glass/releases/tag/v0.1.0-alpha.1) has the notes.
